✨ Added
- Per-topic discovery briefs — at the end of an epic's discovery, each topic gets a brief of soft decisions, rejected paths and open questions that seeds its research or discussion.
- Reconcile advisory — if a brief is regenerated after downstream research or discussion has started, you get a non-blocking notice and the existing work is never overwritten.
- Epic discovery session logs are now indexed in the knowledge base — past exploration is searchable by later phases and sibling epics.
- Discovery gains a gentle "ready to pull topics" nudge when the conversation converges — you decide when to harvest.
- Re-entering an epic's discovery now briefs you on where the previous sessions left off.

🔧 Changed
- Epic discovery is now a deeper, more challenging design conversation that works through decisions, not just a breadth-first sketch.
- Discovery session logs now live in `discovery/sessions/`, with a migration that moves existing logs automatically.
- README getting-started rewritten around a two-step install and `/workflow-start`, with knowledge-base setup details folded away.
- README feature and phase descriptions condensed.

🗑️ Removed
- The Workflow Explorer HTML page and its GitHub Pages deployment.
- Internal planning and design documents (discovery map, knowledge base, incoming, spec groupings).
