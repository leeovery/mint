# Cli Presentation

A styled-but-restrained presentation layer for the mint CLI, applied consistently across every verb (release, regenerate, init, version) rather than only the release run. On an interactive terminal it shows a brand and title, colour, and progress spinners while git and the claude CLI work. When output is not a TTY (piped or redirected, e.g. an AI or agent consuming it) it degrades to token-efficient plain text. Render mode is driven by TTY detection, not environment sniffing. The -y/--yes flag is orthogonal: it only skips the interactive gate stops, so a human at a terminal with -y still gets the styled UI. The open how-question deferred to later phases is which Go packages provide the styling and spinners (a charm/lipgloss-style stack versus lighter colour libraries).
